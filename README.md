## 一、系统定位与双平台架构

“海析智瞳”双平台系统面向现代海洋牧场观测级 ROV 水下作业与底栖生物资源评估业务全流程，将**硬件控制驱动**与**深度学习计算机视觉分析**无缝融合：

1. **ROV 岸端控制平台 (Shore-side Control Platform)**：
   - 采用**深海驾驶舱暗黑工控科技美学**（Deep Sea Navy + Cyber Cyan）。
   - **作业驾驶舱**：三通道 1080P 水下高清视频流、实时动态 HUD 仪表态势仪（人工地平仪/姿态球、航向罗盘磁偏角、水深等深刻度标尺、六自由度动力推力负载环形光条）。
   - **双路大功率补光控制**：实时响应滑块调节，动态改变海床成像曝光与对比度。
   - **视觉辅助主动复拍决策**：内置图像质量门控（曝光指数、边缘锐度、对比度、照度 Lux）。当进入背光/深凹暗光样点时，系统主动弹出智能复拍建议，操作员一键确认后自动化执行“补光升档至 85% + 悬停定深 + 二次快门重采”，并提供复拍前后 Split-Slider 滑块对比视图。
   - **六通道全硬件自检**：通信、相机、IMU、六推进器、补光灯、水密微压传感器一键巡检。
   - **数据交接与任务包导出**：一键移交智能分析平台，并支持导出行业标准 `HXTASK-1.0` ZIP 任务归档包。

2. **FBDPN 智能分析平台 (FBDPN Intelligent Analysis Platform)**：
   - 采用**深海工控专业仪器美学**，兼顾高对比度图像标注辨识与科研报告排版。
   - **调查总览**：多维 KPI 指标流、物种相对丰度环形图、样点生境检出对比柱状图。
   - **三栏检测与复核工作台**：
     - *左栏*：待复核影像队列流（缩略图、清晰度/曝光质量徽标、检出数）。
     - *中栏*：高精度矢量交互画布（支持无级缩放、拖拽平移、框选交互、鼠标拉框补框、阈值联动实时过滤低置信物标、S02 复拍双屏分屏对比）。
     - *右栏*：物标属性检视器（物种类别修正下拉框、模型置信度量表、像素空间坐标、撤销/重做历史栈、一键全图审定通过庆祝彩带）。
   - **调查统计**：集成 ECharts，提供物种修正前后对比柱状图、样点生态多样性雷达图 (Shannon Index)、水深-密度梯级分布曲线。
   - **成果报告预览与交付**：符合 A4 印刷排版的调查评估报告，内嵌航行水文数据、代表性样帧、修正后物种核算表、FBDPN 模型溯源，支持浏览器**一键打印或另存为 PDF**。

## 二、技术栈与工程实现

- **前端架构**：React 18 + TypeScript + Vite + Zustand（全局响应式双平台状态管理与持久化）。
- **组件与视觉库**：Ant Design 5（深度定制科技暗黑主题）+ Lucide Icons + Canvas-Confetti。
- **数据可视化**：Apache ECharts (echarts-for-react)。
- **后端服务**：Node.js + Express + WebSocket (`ws`) + AdmZip（原生支持任务包导出导入）。
- **图像与算法基准**：真实采纳 URPC2020（水下机器人目标检测大赛）海底生物图像，并基于 FBDPN（特征增强与差分特征金字塔水下目标检测网络）权威论文参数建模。

## 三、快速启动与本地运行指南

系统完全解耦外部网络，不依赖任何在线 CDN、外部字体或云端接口，**完全支持离线本地演示**。

### 1. 环境准备
- Node.js >= 18.0.0 (推荐 Node 20 / 22 / 24)
- npm >= 9.0.0

### 2. 一键启动
进入软件目录执行：

```bash
cd 海析智瞳双平台Demo

# 安装依赖（若首次运行）
npm install

# 方式 A：一键运行生产融合服务（推荐，单端口包含前后端）
npm start
# 浏览器访问：http://localhost:3001

# 方式 B：开发者热重载模式（前后端双进程并行）
npm run dev
# 浏览器访问：http://localhost:5173
```

## 五、竞赛评委演示播控中心 (Demo Deck)

在系统任意页面右上角点击 **【演示播控】** 按钮，即可展开独立浮动控制抽屉：
1. **一键重置演示**：将双平台所有任务状态、复拍缓存与复核记录瞬间重置为初始标准演示状态。
2. **六步快捷跳转**：
   - 步骤 1：系统自检与任务启动
   - 步骤 2：样点 S01 驾驶舱正常采集
   - 步骤 3：样点 S02 欠曝告警与智能复拍
   - 步骤 4：样点 S03 与数据交接
   - 步骤 5：FBDPN 接收与人工复核
   - 步骤 6：成果报告与成果归档
3. **故障注入模拟**：可一键模拟“通信高时延 (145ms)”、“动力电量告警 (18%)”、“推进器负载偏高 (88%)”及“恢复正常遥测”。
